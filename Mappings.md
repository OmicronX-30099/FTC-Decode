# @zach5982   Gamepad Mappings
  ## Gamepad 1
    ### * Joysticks: 
      Driving
    ### * Triger
      Right Trigger: Intaking balls + open gate, close gate and stop intake on release
      Left Triger: Outtaking balls + open gate, close gate and stop intake on release
    ### * Bumpers
      Right Bumper: Shoot 1 ball (Kicker + shoot gate)
      Left Bumper: Triple shoot sequence
    ### * Shapes
      Cross: Auto Aim on/off toggle
      Triangle: Slow mode (0.2x speed) (toggles back to normal)
      Square: Medium mode (0.5x speed) (toggles back to normal)
    ### * Dpad
      Dpad left: Reset follower next to the goal
      Dpad right: Reset follower by far launch zone
      Dpad down: Reset follower in the loading zone
      Dpad up: free button
  ## Gamepad 2
    ###  * Joysticks
      Right joystick button enables medium mode (toggles back to normal)
      Left joystick button enables slow mode (toggles back to normal)
    ### * Bumpers
      Left Bumper: Controls Turret turns to left
      Right Bumper: Controls Turret turns to right
    ### * Shapes
      Cross: Pre-spin flywheel close
      Triangle: Pre-spin flywheel far
    ### * Triggers
      Right Trigger: Intaking balls + open gate, close gate and stop intake on release
      Left Trigger: Outtaking balls + open gate, close gate and stop intake on release
  ## RGB Sequencing
    ### * Shooter Indicator
      Color 1 -> Pre-spinning close
      Color 2 -> Pre-spinning far
      Color 3 -> Auto-aiming
    ### * General Indicator
      Color 1 -> Slow mode
      Color 2 -> Medium mode
      Color 3 -> Fast mode
      Color 4 -> One blink when shoot clicked
      Color 5 -> Only while shoot sequence is happening
      Color 6 -> One blink while resetting follower
